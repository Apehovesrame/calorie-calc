# calorie-calc
## Описание предметной области

**Сервис расчета калорийности блюд** — курсовой проект по дисциплине «Разработка корпоративных приложений».  
Система представляет собой клиент-серверное приложение: мобильный клиент на Kotlin (Android) и серверная часть на Java / Spring.

> В задании используется формулировка «веб-приложение», однако клиентская часть реализована как мобильное приложение на Kotlin, которое взаимодействует с сервером по REST API.

### Назначение
Приложение автоматизирует учёт питания, расчёт калорийности и пищевой ценности блюд. Пользователь создаёт собственные рецепты на основе справочника ингредиентов, получает автоматический расчёт КБЖУ, ведёт дневник питания и отслеживает дневную норму калорий.

### Роли пользователей
- **Администратор** — управляет пользователями, ведёт справочник ингредиентов, формирует отчёты.
- **Пользователь** — создаёт блюда через конструктор рецептов, ведёт дневник питания, сохраняет рецепты в личную коллекцию, просматривает сводку за день и следит за нормой калорий.

### Основные возможности
- Конструктор рецептов с автоматическим расчётом итоговой калорийности и КБЖУ.
- Личный дневник питания с учётом потреблённых блюд.
- Сводка по питанию за день.
- Сохранение рецептов в личную коллекцию.
- Управление справочником ингредиентов (для администратора).
- Формирование отчётов в форматах Excel и PDF.
- Отправка уведомлений пользователям по электронной почте.
- Разграничение доступа по ролям.
- Адаптивный интерфейс мобильного приложения под различные размеры экранов.
- Валидация данных на стороне клиента (Kotlin) и на стороне сервера (Spring).
- Модульные тесты для бизнес-логики.

### Ключевые сущности
- **Пользователь** — учётные данные, роль, дневник питания.
- **Ингредиент** — название, калорийность и БЖУ на 100 г.
- **Блюдо** — рецепт, список ингредиентов с количеством, итоговые КБЖУ.
- **Запись дневника** — дата, блюдо, количество, итоговые КБЖУ.
- **Отчёт** — сводные данные по питанию за период.

### Архитектура и технологии
- **Backend:** Java, Spring Boot, Spring MVC, Spring Data JPA, Spring Security, Bean Validation.
- **Frontend:** Kotlin, Android SDK, Retrofit / OkHttp, Coroutines / Flow, Jetpack Compose.
- **База данных:** PostgreSQL.
- **Взаимодействие:** REST API, обмен данными в формате JSON.
- **Отчёты:** Apache POI (Excel), iText / OpenPDF (PDF).
- **E-mail:** JavaMailSender.
- **Тестирование:** JUnit, Mockito.
